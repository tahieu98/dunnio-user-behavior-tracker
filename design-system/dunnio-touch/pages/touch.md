# Touch dashboard

Inherits MASTER.md. Scope and period inputs precede data; one primary analysis action. The four-period demo is a review aid with explicit synthetic warning and no real API calls. Measured mode uses independent blank coordinates until a geometrically compatible snapshot exists. Exact values are available through pointer selection and native tables. A/B comparison direction is always B minus A. Missing observations display an em dash; received pageviews with no taps display zero. Full-page phone screenshots preserve document geometry and may be long; controls and tables remain accessible without document overflow.

Element tables expose centroid/bounds and layout/width/plane context. A/B coordinates remain separately descriptive when geometry changes; signed positional deltas require positionComparable=true and finite positions. Rate denominators are visibly scoped to CSS-width segments.
